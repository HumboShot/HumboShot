## Christian Glarmbæk

Developer based in Denmark. I build tools for my Twitch stream, my music setup and my own daily use.

Current work:

- Overlays, chat games and bots for my Twitch stream
- Now-playing integrations for Discord and OBS
- A native Android client for Koillection

Website: [humboshot.com](https://www.humboshot.com)

### Projects

| Project | Description | Stack |
| --- | --- | --- |
| [nowplaying-rpc](https://github.com/HumboShot/nowplaying-rpc) | Shows what you listen to in Plexamp, Spotify, Apple Music or foobar2000 as Discord Rich Presence, from the system tray. Runs on Windows, macOS and Linux. | C# / .NET |
| [koillection-android](https://github.com/HumboShot/koillection-android) | Goshiki, an unofficial native Android app for [Koillection](https://github.com/benjaminjonard/koillection) servers. | Kotlin |
| [stream-overlays](https://github.com/HumboShot/stream-overlays) | OBS browser-source overlays for my stream: starting, AFK and ending screens, chat, now playing and more. No build step and no dependencies. | HTML / CSS / JS |
| [stream-word-game](https://github.com/HumboShot/stream-word-game) | A chat game for the AFK scene. Emotes appear on screen, and the first chatter to type the name gets the points. | JS / Streamer.bot |
| [website](https://github.com/HumboShot/website) | The source for [humboshot.com](https://www.humboshot.com), a single static page in a terminal style. | HTML / CSS / JS |

### Tools

C#, .NET, Kotlin, JavaScript, OBS, Streamer.bot
