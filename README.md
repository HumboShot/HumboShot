## 👋 Hi, I'm Christian (@HumboShot)

Developer from Denmark 🇩🇰. I mostly build small tools for my Twitch stream, my music setup and my own everyday use.

- 🎙️ Building overlays, chat games and bots for my Twitch stream
- 🎵 Showing what I listen to everywhere, from Discord to OBS
- 📱 Writing a native Android client for Koillection
- 🎮 Trying out game dev in Godot on the side

🌐 [humboshot.com](https://www.humboshot.com)

### 🔨 Projects

| Project | What it is | Built with |
| --- | --- | --- |
| [nowplaying-rpc](https://github.com/HumboShot/nowplaying-rpc) | Shows what you listen to in Plexamp, Spotify, Apple Music or foobar2000 as Discord Rich Presence, from the system tray. Runs on Windows, macOS and Linux. | C# / .NET |
| [koillection-android](https://github.com/HumboShot/koillection-android) | Goshiki, an unofficial native Android app for [Koillection](https://github.com/benjaminjonard/koillection) servers. | Kotlin |
| [stream-overlays](https://github.com/HumboShot/stream-overlays) | OBS browser-source overlays for my stream: starting/AFK/ending screens, chat, now playing and more. No build step, no dependencies. | HTML / CSS / JS |
| [stream-word-game](https://github.com/HumboShot/stream-word-game) | A chat game for the AFK scene. Emotes pop up on screen and the first chatter to type the name gets the points. | JS + Streamer.bot |
| [website](https://github.com/HumboShot/website) | The source for [humboshot.com](https://www.humboshot.com), a single static page in a terminal style. | HTML / CSS / JS |
| [personal-scripts](https://github.com/HumboShot/personal-scripts) | Small scripts I use on a semi-regular basis. | Python |
| [shooter](https://github.com/HumboShot/shooter) | A small shooter game made while learning Godot. | GDScript |
